## 🎯 **Quick Start Paths**

### **For Developers**
1. Read [API.md](./API.md) for architecture overview
2. Follow [DXT_BUILDING_GUIDE.md](./DXT_BUILDING_GUIDE.md) for packaging
3. Use [LLM recipes](./llm-recipes/) for AI-assisted development

### **For VRChat Integration**
1. Review [VRCHAT_INTEGRATION.md](./VRCHAT_INTEGRATION.md)
2. Set up Unity with [VRCHAT_UNITY_SETUP.md](./VRCHAT_UNITY_SETUP.md)
3. Test with VRChat-compatible VRM models

### **For AI-Assisted Development**
1. Choose your LLM model from [llm-recipes](./llm-recipes/)
2. Follow the specific recipe for optimal results
3. Contribute back with improvements and new recipes
