# Glama.ai Rescan Guide for AvatarMCP

## 🎯 When to Request a Rescan

### Major Updates Requiring Rescan
After any significant changes that affect quality metrics:

- ✅ **New releases** (version bumps)
- ✅ **Major feature additions** (new MCP tools)
- ✅ **Quality improvements** (test coverage, documentation)
- ✅ **CI/CD pipeline changes** (new workflows)
- ✅ **Security updates** (dependency changes)

### Quality Metric Changes
Request rescans when you've improved:

- **Test coverage** increases significantly
- **Documentation** completeness improves
- **Code quality** enhancements
- **Security** fixes implemented
- **Performance** optimizations

## 📧 How to Request a Rescan

### Step-by-Step Process

1. **Prepare Your Repository**
   - Ensure all CI/CD pipelines are passing
   - Verify documentation is up to date
   - Confirm all quality metrics are optimized
   - Check that recent commits are pushed

2. **Use the Email Template**
   - Copy the template from `GLAMA_RESCAN_EMAIL.txt`
   - Fill in your repository details
   - Include specific changes made
   - Send to support@glama.ai

3. **Monitor Progress**
   - Check repository status on Glama.ai
   - Watch for quality score updates
   - Verify new version detection

## 📋 What Gets Rescanned

### Repository Analysis
- **Codebase Structure**: File organization and patterns
- **Quality Metrics**: Print statements, logging, error handling
- **Test Results**: CI/CD status and coverage reports
- **Documentation**: Completeness and formatting
- **Dependencies**: Security and compatibility

### Platform Updates
- **Version Detection**: Latest release identification
- **Quality Scoring**: Recalculation of all metrics
- **Ranking Updates**: Position changes in listings
- **Metadata Refresh**: Description and category updates

## 🚨 Troubleshooting Rescan Issues

### Common Problems

#### "Repository not found"
- Verify repository is public
- Check repository name spelling
- Ensure GitHub App permissions

#### "No changes detected"
- Confirm commits are pushed
- Check CI/CD completion
- Verify documentation updates

#### "Quality metrics unchanged"
- Review actual code changes
- Check CI/CD test results
- Validate documentation completeness

### Resolution Steps

1. **Verify Repository Status**
   - Check GitHub repository visibility
   - Confirm CI/CD pipelines passing
   - Validate recent commit activity

2. **Check Platform Integration**
   - Verify GitHub App installation
   - Confirm webhook configuration
   - Review repository permissions

3. **Prepare Detailed Request**
   - Include specific changes made
   - Provide before/after metrics
   - List quality improvements
